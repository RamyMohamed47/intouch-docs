# Engineering Context Mirrors

This section contains repository-facing context mirrored from the application
repository's `.agents` directory. It is separated from the numbered
human-facing documentation so readers can distinguish explanatory
documentation from agent and implementation inputs.

## Editing Policy

Do not edit mirrored files here as their primary source. Update the canonical
file in the application repository, validate it with the implementation, and
then refresh the corresponding mirror in this vault.
