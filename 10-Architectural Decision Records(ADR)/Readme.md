# Architecture Decision Records (ADRs)

This directory contains the major architectural decisions made during the design and development of InTouch.

## ADR Index

| ADR     | Title                     | Status   |
| ------- | ------------------------- | -------- |
| ADR-001 | Multi-Tenancy Strategy    | Accepted |
| ADR-002 | MongoDB Selection         | Accepted |
| ADR-003 | Conversation Model        | Accepted |
| ADR-004 | Identity Linking Strategy | Accepted |

Each ADR documents:

- The context of the decision.
- The chosen solution.
- Alternatives considered.
- Trade-offs.
- Consequences.
