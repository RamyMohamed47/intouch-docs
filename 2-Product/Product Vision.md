
## Project Name

InTouch

---

## Overview

InTouch is a multi-tenant real-time communication platform inspired by Discord and Slack.

Organizations can create isolated workspaces where members communicate through channels and direct messages in real time.

The project is intended to demonstrate production-ready backend engineering concepts including multi-tenancy, authentication, authorization, WebSockets, background jobs, caching, and scalable architecture.

---

## Goals

- Build a production-quality portfolio project.
- Demonstrate backend architecture beyond CRUD.
- Implement real-time communication using Socket.IO.
- Design a scalable multi-tenant system.
- Learn software architecture and system design.

---

## Non-Goals

The first version will NOT include:

- Voice calls
- Video calls
- Screen sharing
- End-to-end encryption
- AI assistant
- Bots
- Calendar integration

These may be considered in future versions.
